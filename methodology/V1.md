# HStat.India V1 methodology

## Product rule
- Global comparison: HS-6 only.
- India drill-down: ITC(HS)-8 only after mapping to the parent HS-6 code.
- Never compare an Indian 8-digit national subdivision directly across countries.

## Data layers
1. Raw: exact source snapshots, immutable.
2. Clean: harmonised product/country/time fields and data-quality flags.
3. Analytics: derived indicators used by the interface.
4. Curated: supply-chain edges and MeitY product-family metadata, each with evidence and confidence.

## Core indicators
- Trade value: source-reported USD value.
- Trade balance: exports minus imports.
- YoY growth: current / prior period minus 1.
- CAGR: compound annual growth across selected window.
- Global export share: reporter exports / summed comparable reporter exports.
- Largest supplier share: largest partner import value / reporter imports from all partners.
- Top-3 supplier share: top 3 partner import value / reporter imports from all partners.
- HHI: sum of squared partner shares. UI converts this to a documented Low/Moderate/High band.

## Interpretation rule
V1 plain-language insights must be deterministic outputs from stored indicators and thresholds. No LLM-generated statistics or unsupported causal statements.

## Provenance
Every data load receives a manifest containing source, extraction time, classification, scope, row counts, processing version and raw-object location.

## Real-data rule (v0.2)
HStat.India does not publish synthetic trade values. HS-6 trade values shown in the interface are generated from authenticated UN Comtrade final-data records. Missing layers remain visibly unavailable rather than being inferred.

For global comparisons, the pipeline sums available country/area reporters' exports to World for the selected HS-6 and labels this explicitly as **reported world exports**. It is not presented as an independently estimated global total. India's global rank and share are calculated against the same retrieved reporter set.

India's ITC(HS)-8 layer is not derived by splitting HS-6 Comtrade data. It requires a separate India-specific tariff-line source. Upstream/downstream supply-chain relationships likewise remain a separately sourced curated layer.
