# Reference-data policy

This directory is for small, version-controlled reference and mapping files only:
- MeitY product families and included HS-6 codes.
- HS version/concordance metadata.
- India ITC(HS)-8 to parent HS-6 mappings.
- Curated supply-chain relationships with evidence/confidence.

Large trade files belong in R2 / raw data storage, not GitHub.
