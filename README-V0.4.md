# HStat.India V0.4 — discovery, India-8, country rankings and presentation

V0.4 adds:
- searchable HS-2/4/6 library under MeitY headings 8471, 8473, 8507, 8517, 8541, 8542;
- keyword/tag-assisted search and quick-access codes;
- light/dark and compact/dense modes;
- FED-inspired navy/green visual system using the supplied FED mark;
- populated India Position, Dependencies and Methodology views;
- top exporter/importer country tables when global data has been refreshed;
- India tariff-line (8-digit) integration in the product refresh pipeline;
- curated supply-chain context kept explicitly separate from observed trade statistics;
- CSV/JSON table downloads and SVG/PNG chart downloads.

The UI must never invent an unavailable statistic. Library presence and data availability are separate states.
